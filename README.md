## Sobre o projeto

O projeto Barbearia tem como proposta desenvolver uma solução computacional relacionada às atividades de uma barbearia.

A aplicação pode ser utilizada como base para organizar informações e processos do negócio, de acordo com as funcionalidades implementadas no código-fonte.

Este repositório reúne os arquivos necessários para o desenvolvimento e a evolução do projeto.

## Objetivos

- Aplicar conhecimentos de desenvolvimento de software.
- Organizar o código-fonte de maneira estruturada.
- Desenvolver uma solução relacionada ao contexto de uma barbearia.
- Facilitar a manutenção e a evolução da aplicação.
- Documentar os procedimentos de configuração e execução.
